# zujuan-spider (组卷网爬虫)

一个用于抓取 **[组卷网]** (zujuan.xkw.com) 上**知识点信息**与**章节内容信息**的 Python 爬虫工具。

## ✨ 功能

- 抓取指定科目的**知识点**结构。
- 抓取教材的**章节目录**与对应的试题/内容。
- 将抓取的数据结构化输出，便于后续分析或入库。
- （根据你的代码）包含多个版本的实现，供参考或迭代。

## 📁 项目结构

```
.
├── data/                    # 存放原始数据或中间数据
├── output/                  # 存放最终输出的结果文件
├── main第2版-目录结构get.py   # 专门抓取目录结构的脚本
├── main第2版-知识点get.py     # 专门抓取知识点的脚本
└──  test.py                  # 测试脚本
```

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/zhaozeru/zujuan-spider.git
cd zujuan-spider
```

### 2. 安装依赖

建议使用虚拟环境，并安装必要的库：

```bash
pip install requests beautifulsoup4 lxml
```

> 如果代码中使用了其他库（如 `selenium`、`pandas` 等），请根据实际情况补充安装。

### 3. 运行爬虫

根据不同需求，选择运行对应的脚本：

```bash
# 或单独抓取知识点
python main第2版-知识点get.py

# 或单独抓取目录结构
python main第2版-目录结构get.py
```

## 📄 输出说明

- 抓取结果通常保存在 `output/` 目录下。
- 文件格式可能为 JSON、CSV 或文本，具体取决于代码实现。

## ⚠️ 注意事项

1. **尊重网站 robots.txt**：请遵守组卷网的爬虫协议，控制抓取频率，避免对目标网站造成压力。
2. **数据使用**：抓取的数据仅可用于个人学习、研究，请勿用于商业用途或侵犯网站权益。
3. **网站结构变动**：爬虫基于特定页面结构编写，如果网站改版，代码可能需要相应调整。
